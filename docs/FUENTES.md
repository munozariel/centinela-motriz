# Fuentes

## Caso de referencia

- Equalis LLC, [Equalis Predictive Motor Maintenance (PMM): Beta Program Summary](https://www.equalis.com/single-post/2017/10/02/Equalis-Predictive-Motor-Maintenance-PMMBeta-program-summary-October-2nd-2017), 2017. Prototipo de monitoreo de motores con un microcontrolador y un acelerómetro, que presenta el estado del motor con un indicador verde, amarillo y rojo. Es un caso comparable a este proyecto, con un enfoque similar.

## Mantenimiento

- Norma EN 13306, *Mantenimiento: terminología*. Define los tipos de mantenimiento (preventivo, correctivo, predictivo) que se usan en el registro de la app.
- Norma ISO 17359, *Monitoreo de condición y diagnóstico de máquinas*. Describe el uso de una línea base y de criterios de alerta, que es como el kit evalúa los cambios.

## Sensor
